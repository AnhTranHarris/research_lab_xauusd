## 4. Candle Construction
For interval `[t_0,t_1)`, define a price series `p_t`. Bid, ask, and mid-price bars should remain distinguishable when required.
Mid:
`m_t = (bid_t + ask_t)/2`
OHLC:
`O = first(p_t)`  
`H = max(p_t)`  
`L = min(p_t)`  
`C = last(p_t)`
Tick count:
`N = number of ticks in [t_0,t_1)`
Spread statistics:
`S_mean = mean(ask_t-bid_t)`  
`S_max = max(ask_t-bid_t)`
Directional efficiency:
`eta = |C-O| / (sum_k |p_k-p_{k-1}| + epsilon)`
Range:
`R = H-L`
Turn count:
`T = sum_{k=2}^n 1[sign(Delta p_k) != sign(Delta p_{k-1})]`
For 250 ms bars, boundaries must be deterministic and aligned to UTC clock quarters:
00.000–00.250, 00.250–00.500, 00.500–00.750, 00.750–01.000.
For nonstandard M7 bars, document the anchor explicitly. Default anchor is UTC midnight unless project evidence specifies another causal session anchor.

## 7. Core Trade Mathematics
For trade `i`, signed direction `d_i in {+1,-1}`, entry `P_i^0`, and mark `P_i(t)`:
`E_i(t) = d_i [P_i(t)-P_i^0]`
`MFE_i(t) = max_{0<=u<=t} E_i(u)`
`MAE_i(t) = max_{0<=u<=t} [-E_i(u)]`
Net trade P&L:
`pi_i = V_i d_i(P_i^exit-P_i^0) - C_i`
where `C_i` includes modeled spread, commission, and slippage.
Profit factor:
`PF = sum max(pi_i,0) / |sum min(pi_i,0)|`
Win rate:
`WR = N(pi_i>0)/N`
Expectancy:
`E[pi] = WR*AW - (1-WR)*AL`
Loss efficiency:
`LE = NetProfit / |GrossLoss|`
Drawdown efficiency:
`DE = NetProfit / MaxDrawdown`
A useful loss-aware research objective is:
`J = NetProfit - lambda|GrossLoss| - mu MaxDrawdown`
